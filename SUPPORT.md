# Support

## 1. Where to Go

| You need | Go here |
|---|---|
| Help using the project | [GitHub Discussions | #help channel | support email] |
| To report a bug | Open an issue with the **Bug report** template |
| To ask for a feature | Open an issue with the **Feature request** template |
| To report a security problem | Follow [SECURITY.md](SECURITY.md). Never use a public issue. |
| Urgent production problem (internal staff) | Page on call through [tool or channel]. See [docs/RUNBOOK.md](docs/RUNBOOK.md). |
| To report a conduct problem | Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Help setting up your machine | [docs/SETUP.md](docs/SETUP.md) and [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) |

## 2. Before You Ask

1. Search the docs, closed issues, and [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
2. Check that you use a supported version (see [SECURITY.md](SECURITY.md)).
3. Try to reproduce the problem on the latest version.

## 3. How to Write a Good Request

Include:
* Version, operating system, and environment (local, staging, production)
* What you did, what you expected, and what happened
* Exact error text and logs (remove secrets and personal data first)
* The smallest example that shows the problem
